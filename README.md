# Frigo & Fitness App 🏋️‍♂️🍏

Benvenuto nel repository ufficiale dell'app **Frigo**, un'applicazione iOS completa (sviluppata in SwiftUI) progettata per aiutarti a gestire a 360 gradi la tua routine di benessere quotidiano: dall'allenamento in palestra alla gestione dell'alimentazione e delle scorte nel frigorifero.

## 📝 Descrizione del Progetto (per la pagina GitHub)

*Ti consiglio di incollare questo testo nella sezione "About" in alto a destra nella tua pagina GitHub:*

> **"Un'app iOS in SwiftUI per la gestione integrata dello stile di vita: tracciamento degli allenamenti in palestra, gestione intelligente delle scorte in frigorifero e pianificazione dei pasti."**

## ✨ Funzionalità Principali

* **🏋️ Allenamento (Gym & Workout):** Crea schede di allenamento, monitora le sessioni attive, traccia gli esercizi in tempo reale e sincronizza i tuoi progressi.
* **🍏 Cibo e Frigorifero:** Tieni traccia delle scorte alimentari nel tuo frigo, pianifica la routine dei pasti (Meal Routine) ed evita gli sprechi.
* **🏠 Dashboard (Home):** Una vista centralizzata per avere subito sott'occhio le tue attività di oggi, sia per il cibo che per la palestra.
* **👤 Profilo:** Gestisci i tuoi dati personali, le preferenze e lo storico delle attività.
* **📱 Widget (FrigoWidget):** Supporto per i Widget iOS per accedere alle informazioni più importanti direttamente dalla Home Screen o Lock Screen del tuo iPhone.

## 🛠️ Tecnologie Utilizzate

* **Linguaggio:** Swift
* **Framework:** SwiftUI
* **Architettura:** Pattern architetturali moderni (MVVM / Manager Pattern)
* **Testing:** XCTest per Unit Test (es. `MealRoutinePlannerTests`)
* **Strumenti AI:** Framework multi-agente per lo sviluppo e l'integrazione.

## 🚀 Setup e Installazione

1. Clona il repository sul tuo Mac:
   ```bash
   git clone <URL_DEL_TUO_REPO>
   ```
2. Apri il file `Frigo.xcodeproj` con Xcode.
3. Seleziona il simulatore iOS desiderato o collega il tuo dispositivo fisico.
4. Clicca su **Run** (oppure premi `Cmd + R`) per compilare e avviare l'app.

## 📂 Struttura del Progetto

* `/Frigo/Allenamento/`: Logica, viste e modelli per il mondo fitness.
* `/Frigo/Cibo/`: Core logic per frigorifero e meal planner.
* `/Frigo/Home/`: Dashboard unificata.
* `/Frigo/Profilo/`: Impostazioni utente.
* `/FrigoTests/`: Suite di test automatizzati per il controllo qualità.
